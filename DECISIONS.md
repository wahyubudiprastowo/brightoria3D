# Architecture Decision Record

## ADR-001 Web-first Three.js plus Capacitor
Status: accepted. Reason: one stable Three.js renderer for web and Android WebView.

## ADR-002 DOM overlay over fully 3D UI
Status: accepted. Reason: accessibility, text clarity, forms, payment security, responsive layout.

## ADR-003 No background music
Status: accepted. Engagement comes from interaction, transformation, narration, optional ambience and haptics.

## ADR-004 Consumer-first product
Status: accepted. Bright Academy is endorsement/provider; parent can use Brightoria independently.
